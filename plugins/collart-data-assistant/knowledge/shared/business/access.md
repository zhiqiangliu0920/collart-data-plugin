# 只读、最近 7 天与连接约定

## 数据权限与查询边界

只允许 SELECT / WITH SELECT 和读取表元数据；禁止 INSERT、UPDATE、DELETE、MERGE、TRUNCATE、CREATE、ALTER、DROP、CALL、EXPORT、权限变更及通过 API/脚本实现同等写入。不得运行 SQLX、生成器、回填、建表或调度任务。知识维护只改已授权的知识文件。

原始事件及可还原逐条行为的 DWD/DM 明细只允许最近 **7 天**。默认 Asia/Shanghai 的最近七个完整日 `[今天-7, 今天-1]`；需要今天时只允许 `[今天-6, 今天]`，标明未定稿。不得选任意历史七日窗口、分批绕过、跨入口扩大扫描或用 LIMIT 替代日期限制。每个原始事件扫描都有日期上下界和产品条件；finalized 与 intraday 分开且去重。

ADS、用户日汇总、画像及合法收入/成本表可做更长期分析。数仓自身 30 日/更长刷新与留存观察窗保持原样；查询约束不要求修改生产任务。

## 连接与执行

使用同事自己的已授权连接，先确认项目/计费项目、数据集与只读能力。缺少连接时交付口径、参数化 SQL 和待核验项，不声称查过数据、不借用维护者凭证。原始查询通过 `scripts/query.py raw-events` 生成固定边界模板，或按同样边界人工审核 SQL。SQL 工具本身不连接数仓。

插件规则不能撤销连接已有的写权限，也不能拦截其他工具直接执行 SQL。真正的只读保障应由数仓 IAM / 只读视图 / 查询网关执行；七天限制若需不可绕过，也须在数据服务侧实施。当前插件没有安装数据库权限策略。

## 内部账号与隐私

Web/Fashion 默认按事件发生时 user_id 排除内部账号，允许匿名的指标保留 NULL；付费账号须用有效身份。内部名单由使用者授权的数据源提供，须非空、无 NULL、无重复；本包不分发实际账号或分析结果。未取得名单时不能把过滤标为完成。整设备历史绑定排除是额外口径，可能连带真实客户，需单独说明。

输出优先聚合，必要的单用户分析不复制到团队知识。库中没有密钥或通用数据库连接。
