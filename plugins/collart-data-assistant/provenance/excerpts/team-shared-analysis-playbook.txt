# 经营变化分析的取数与判断流程

## 输入与路径

先明确项目、时间窗、对照周期和要支持的业务决策。总量用 daily 起步；按需要拆国家、渠道、新老结构，再看对应的功能或支付漏斗。

数据新鲜度与定义变化先排除，再解释业务变化。对国家/渠道拆分给出变化量及其对总变化的贡献，不只看涨跌百分比。总体指标变化也可能来自结构占比变化。

收入拆分同时关注用户量、付费率、每付费用户收入；分母和收入范围需一致。时间窗未完整、事件缺失、样本过小或归属不清时，标为证据不足，避免从相关性直接断言因果。

## 输出与沉淀

交付说明采用的指标定义、覆盖日期、来源层、关键数值、可复现 SQL 与限制。沉淀到知识库的是可复用定义、稳定业务规则、验证方法或明确范围的数据问题；单次报告结论保留在分析交付物中。

本条是基于既有诊断资料整理的方法建议，不承诺固定指标水平，也不把历史经营目标作为当前团队目标。
