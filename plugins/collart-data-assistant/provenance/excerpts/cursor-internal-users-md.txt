# 内部用户过滤

## 口径

做任何 **Collart Web / Fashion** 统计分析（用户、行为、转化、收入、留存、渠道、漏斗、生成）时，必须从口径中排除下列内部用户。

- 过滤字段：`user_id`
- 凡 SQL 存在 `user_id` 粒度或可关联到 `user_id`，均需排除。
- 若原始数据只有 `user_pseudo_id` 且无法可靠映射 `user_id`，交付结论中必须说明该限制。
- 内部用户**不计入投放效果**评估。
