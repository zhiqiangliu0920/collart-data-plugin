# 📈 指标档案：CONVERSION (Web)

## 1. 基本定义与业务口径
## 口径定义

订阅转化率：完成订阅购买的用户数占总活跃用户的比例。

## 计算逻辑

| 要素 | 说明 |
|------|------|
| 付费事件（埋点） | `vip_subscribe_succeed` |
| 付费订单（服务端，2026-09-07） | Stripe `dwd_cdct_revenue_stripe_di`（`revneue>0`）或 `ads_oper_user_active_di.revenue`；**不要用 `ods.orders`，不要用空表 HI** |
| 分母 | DAU（`session_start` 去重用户数） |

> 用 orders 补数或交叉验证时，禁止把 `pending` / `expired` 当作成功付费。
