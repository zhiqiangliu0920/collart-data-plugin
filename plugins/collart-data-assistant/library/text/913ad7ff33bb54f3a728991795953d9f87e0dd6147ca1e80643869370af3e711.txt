## 核心字段

| 字段名 | 类型 | 说明 |
|:---|:---|:---|
| event_date | DATE | 事件日期 |
| user_pseudo_id | STRING | 用户伪ID（去重标识） |
| is_new | STRING | 新老用户标识 |
| country | STRING | 国家/地区 |
| package_name | STRING | 应用包名 |

## 常用过滤条件

- `package_name = 'free.ai.photo.generator.collart.ai'` - Collart Android 端
- `event_date >= DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY)` - 近30天

## 典型用法

### 获取 DAU 和新老用户分布
```sql
SELECT
  event_date,
  is_new,
  COUNT(DISTINCT user_pseudo_id) AS dau
FROM aidata2025.dwd.dwd_oper_user_collart_di
WHERE event_date BETWEEN DATE_SUB(CURRENT_DATE(), INTERVAL 7 DAY) AND DATE_SUB(CURRENT_DATE(), INTERVAL 1 DAY)
  AND package_name = 'free.ai.photo.generator.collart.ai'
GROUP BY event_date, is_new
ORDER BY event_date DESC
```

### 与 Firebase 事件关联（用户行为分析）
```sql
WITH feature_clicks AS (
  SELECT
    PARSE_DATE('%Y%m%d', event_date) AS event_date,
    user_pseudo_id,
    event_name,
    (SELECT value.string_value FROM UNNEST(event_params) WHERE key = 'feature') AS feature
  FROM `storytemplate-10a27.analytics_232977577.events_*`
  WHERE _TABLE_SUFFIX BETWEEN FORMAT_DATE('%Y%m%d', DATE_SUB(CURRENT_DATE(), INTERVAL 7 DAY))
    AND FORMAT_DATE('%Y%m%d', DATE_SUB(CURRENT_DATE(), INTERVAL 1 DAY))
    AND app_info.id = 'free.ai.photo.generator.collart.ai'
    AND event_name = 'home_feature_click'
)

SELECT
  a.event_date,
  a.is_new,
  COUNT(DISTINCT a.user_pseudo_id) AS dau,
  COUNT(DISTINCT CASE WHEN fc.feature = 'aiVideo' THEN a.user_pseudo_id END) AS ai_video_uv
FROM aidata2025.dwd.dwd_oper_user_collart_di a
LEFT JOIN feature_clicks fc ON a.event_date = fc.event_date AND a.user_pseudo_id = fc.user_pseudo_id
WHERE a.event_date BETWEEN DATE_SUB(CURRENT_DATE(), INTERVAL 7 DAY) AND DATE_SUB(CURRENT_DATE(), INTERVAL 1 DAY)
  AND a.package_name = 'free.ai.photo.generator.collart.ai'
GROUP BY ALL
```
