# BigQuery 执行规则 (2026-03-17 确定)

⚠️ **严格执行红线，违规即视为任务失败：**

| 规则 | 说明 |
|:---|:---|
| **年份确认** | 必须确认是 2026 年（避免误用历史过期表）。 |
| **30天限制** | `events*` 表查询绝对不能超过 30 天，严控资源消耗。 |
| **分区过滤** | 必须显式使用 `_TABLE_SUFFIX`。 |
| **Web过滤** | Web 端查询必须带上 `app_info.id IS NULL`。 |
