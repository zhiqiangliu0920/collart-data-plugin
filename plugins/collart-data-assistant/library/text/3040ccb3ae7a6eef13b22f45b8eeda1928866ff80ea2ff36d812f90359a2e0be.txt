# Collart Web 内部用户过滤规则

## 口径

后续做任何 Collart fashion 统计分析时，必须将下列内部用户从统计口径中排除。

- 适用范围：Collart fashion 的用户、行为、转化、收入、留存、渠道、漏斗、生成等统计分析。
- 过滤字段：`user_id`。
- 默认处理：凡 SQL 中存在 `user_id` 粒度或可关联到 `user_id`，均需排除这些 ID。
- 例外说明：如果原始数据只保留 `user_pseudo_id` 且无法可靠映射到 `user_id`，交付结论中必须说明该限制。

## 推荐 SQL 写法

优先引用 SQL preset：

```text
collart_web/sql_presets/internal_user_filter.sql
```

核心过滤条件：

```sql
AND (
  user_id IS NULL
  OR user_id NOT IN (SELECT user_id FROM internal_users)
)
```

如统计对象必须为登录用户或付费用户，应直接使用：

```sql
AND user_id NOT IN (SELECT user_id FROM internal_users)
```
