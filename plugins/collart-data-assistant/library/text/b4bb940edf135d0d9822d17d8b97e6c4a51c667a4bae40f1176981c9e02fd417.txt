# `aidata2025.ads_collartandroid.ads_oper_user_event_metric_di`

> 文档整理：2026-09-12；业务状态：documented；复核：reviewed_static。原业务日期见正文，本次未重新查询生产数据。


## 1. 基础信息

- 表中文名：Collart Android 用户日事件指标宽表
- 粒度：`event_date × user_pseudo_id`
- 分区：`event_date`；聚簇：`user_pseudo_id`
- 更新：Dataform 日刷近 30 日
- 上游：
  - `aidata2025.dm.dm_collart_android_user_event_di`
  - `aidata2025.ads_collartandroid.ads_oper_user_active_di`（`is_active=TRUE`）
  - 列清单来自 `ads_dim_metric_rule`（`is_materialized=TRUE`）；运行时 **不 JOIN** 规则表

## 2. 核心作用

热漏斗用户日 `*_pv`。下游 attr / country / daily 上卷。冷指标不进本表。

## 3. 字段口径

- 列名 = 规则 `metric_name`，一律 `*_pv`。
- `count_events` → `COUNTIF`；`count_distinct_task_id` → `COUNT(DISTINCT IF(..., task_id, NULL))`。
- 上卷 UV：`COUNTIF(*_pv > 0)`。
- `is_new` / `is_vip` 不落本表，JOIN active。

2026-09-02 热列 27 个，与 Sheet 对齐。冷：`ai_tool_execute_start_pv`。

## 4. 查询示例

```sql
SELECT
  m.event_date,
  COUNTIF(a.is_new AND m.home_show_pv > 0) AS new_home_show_uv,
  SUM(m.video_generate_start_pv) AS video_generate_start_pv
FROM `aidata2025.ads_collartandroid.ads_oper_user_event_metric_di` AS m
JOIN `aidata2025.ads_collartandroid.ads_oper_user_active_di` AS a
  USING (event_date, user_pseudo_id)
WHERE m.event_date >= DATE_SUB(CURRENT_DATE(), INTERVAL 7 DAY)
GROUP BY m.event_date;
```

## 5. 数据质量

- 稀疏：当日无热事件的活跃用户不出行；DAU 分母用 active。
- 扩列必须 `ALTER TABLE ADD COLUMN`，然后回补。
