# 表名：pubdata2025.dwd.dwd_cdct_revenue_stripe_di

## 1. 基础信息
- 表中文名：collart web产品订单记录表(支付平台)
- 表类型：事实表
- 表描述：每个用户每一笔订单的记录
- 行粒度：订单粒度，transaction_id
- 分区字段：event_date
- 更新频率：每日北京时间8点左右自动更新
- 上游来源：支付平台api拉取
- 优先级：高
- 成本效率：低

## 2. 核心作用
本表主要用于以下场景：
- 计算每日收入、首次订阅收入、点数包收入、续订收入使用
- 分析收入的国家分布

## 3. 核心字段
字段名：event_date
- 类型：DATE
- 字段角色：时间维度 / 分区字段
- 业务含义：订单发生日期，用于标识用户行为发生的自然日期

字段名：description_type
- 类型：string
- 字段角色：订单是首次订阅（Subscription creation）、续订（Subscription update）还是点数包收入（credit）

字段名：revneue
- 类型：FLOAT64
- 字段角色：订单价格
- 业务含义：收入 USD；字段名保持源表拼写 `revneue`

## 6. 数据质量与风险提示
-此表有重复数据，因此在分析计算前以transaction_Id为基础，进行去重处理
- Fashion 收入需限定 `app_name = 'collart_web' AND revneue > 0`，再按 `user_id` 关联 Fashion succeed 用户；不能直接使用 Web 全站收入。
- 当前 Fashion 订单入口为 `aidata2025.ads_collartfashion.ads_oper_user_revenue_di`；旧用户日表已于 2026-09-09 停写。交易按前后 600 秒最近支付成功事件确定场景，见收入定义。

## 7. 典型使用场景与示例 SQL
###1 计算不同国家每天的首次订阅收入、续订收入和点数包收入  
``` 
 select event_date
,c.country_name country
,sum(case when revneue>0 then revneue end) revenue
,sum(case when description_type ='Subscription creation' then revneue end)  new_revenue
,sum(case when description_type = 'Subscription update' then revneue end) renew_revenue
,sum(case when  revneue>0 and description_type='credit'  then revneue end) pack_revenue
from (select distinct event_date
,event_timestamp
,transaction_Id
,app_name
,charge_type
,country
,stripe_customer_id
,amount
,fee
,revneue
,description_type
,product_name
from pubdata2025.dwd.dwd_cdct_revenue_stripe_di) a
left join hzdw2024.hz_dim.dim_country c on lower(if(a.country='Russia','ru',a.country))=lower(country_name_3)
where a.country is not null 
and revneue>0
group by all
```
