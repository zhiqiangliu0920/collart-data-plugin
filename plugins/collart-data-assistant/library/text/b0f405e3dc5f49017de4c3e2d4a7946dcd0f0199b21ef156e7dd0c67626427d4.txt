# Collart Web 页面结构

> 文档整理：2026-09-12；业务状态：documented；复核：reviewed_static。原业务日期见正文，本次未重新查询生产数据。


## 页面层级

```
首页 (Home)
    │
    ├── AI Video 功能页
    │       ├── img2video
    │       ├── text2video
    │       └── frames_transition
    │
    ├── AI Image 功能页
    │       ├── img2img
    │       └── text2img
    │
    ├── AI Edit 功能页
    │       ├── faceretouch
    │       ├── improve
    │       └── remove
    │
    └── 其他工具页
            ├── AI Remove
            └── AI Upscale
```

## 埋点事件对应

| 页面 | 进入事件 | 参数 |
|------|---------|------|
| 首页 | page_view | page_location |
| AI Video | aivideo_edit_show | type |
| AI Image | aiimage_edit_show | type |
| AI Edit | aiedit_show | - |

## 与 Android 端差异

| 维度 | Web | Android |
|------|-----|---------|
| 页面类型 | page_view | screen_view |
| 设备字段 | device.browser | device.operating_system |
| 典型事件 | page_view, click | app_open, screen_view |
