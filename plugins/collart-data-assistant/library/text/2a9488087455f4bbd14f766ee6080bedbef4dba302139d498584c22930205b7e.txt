## 表定位
Firebase / GA4 导出到 BigQuery 的原子事件明细表。  
每行代表一次事件上报记录。  

**⚠️ 重要：此表 Web 端和 Android 端共用**，需通过 `app_info.id` 或 `platform` 字段区分项目数据。

**相关产品信息** → 见 [product/home_screenshots.md](../product/home_screenshots.md) 和 [product/core_metrics.md](../product/core_metrics.md)

**完整字段定义** → 见 [collart_web/tables/storytemplate-10a27.analytics_232977577.events_.md](../../collart_web/tables/storytemplate-10a27.analytics_232977577.events_.md)

## 项目数据区分

| 项目 | 过滤条件 |
|------|----------|
| Collart Android | `app_info.id = 'free.ai.photo.generator.collart.ai'` |
| Collart Web | `app_info.id IS NULL` |

## 查询限制（很重要）

### ⚠️ 日期过滤规则（严格禁止违规）
- **必须使用 `_TABLE_SUFFIX` 过滤日期范围**
- **严格禁止**使用 `event_date` 字段替代 `_TABLE_SUFFIX` 进行日期过滤
- `_TABLE_SUFFIX` 是表分区字段，使用它能大幅减少扫描数据量
- `event_date` 只是普通字段，用它过滤会导致全表扫描，查询性能极差

### 正确示例
```sql
-- ✅ 正确：使用 _TABLE_SUFFIX 过滤日期
WHERE _TABLE_SUFFIX BETWEEN '20250301' AND '20250307'
  AND event_date BETWEEN '20250301' AND '20250307'  -- 分析使用的日期字段
```

```sql
-- ❌ 错误：仅用 event_date 过滤（严格禁止）
WHERE event_date BETWEEN '20250301' AND '20250307'
```

### 其他限制
- 单次查询时间跨度不能超过 30 天，如果用户请求超过 30 天，需要经过批准
- **必须过滤项目**：Android 端使用 `app_info.id = 'free.ai.photo.generator.collart.ai'`

# 2. Android 端专用说明

## Android 端典型查询示例

### 示例1：Android DAU
```sql
SELECT
  PARSE_DATE('%Y%m%d', event_date) AS stats_date,
  COUNT(DISTINCT user_pseudo_id) AS dau
FROM `storytemplate-10a27.analytics_232977577.events_*`
WHERE _TABLE_SUFFIX BETWEEN FORMAT_DATE('%Y%m%d', DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY))
  AND FORMAT_DATE('%Y%m%d', CURRENT_DATE())
  AND app_info.id = 'free.ai.photo.generator.collart.ai'  -- Android 端过滤
  AND event_name = 'session_start'
GROUP BY stats_date
ORDER BY stats_date;
```

### 示例2：Android 端事件统计
```sql
SELECT
  event_name,
  COUNT(*) AS event_count,
  COUNT(DISTINCT user_pseudo_id) AS user_count
FROM `storytemplate-10a27.analytics_232977577.events_*`
WHERE _TABLE_SUFFIX BETWEEN '20260101' AND '20260107'
  AND app_info.id = 'free.ai.photo.generator.collart.ai'  -- Android 端过滤
GROUP BY event_name
ORDER BY event_count DESC;
```
