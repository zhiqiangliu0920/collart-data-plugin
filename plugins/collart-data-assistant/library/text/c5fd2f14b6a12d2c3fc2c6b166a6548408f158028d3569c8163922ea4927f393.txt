# 表名：aidata2025.ads_collart.ads_high_value_user_android_Info_ignore_copy

## 1. 基础信息

- 中文名：大R忽略名单副本（普通表）
- 表类型：辅助名单表
- 行粒度：每个 `user_id` 一行
- 分区：无
- 更新频率：手工复制；不是 Drive 外表实时同步
- 上游来源：`aidata2025.ads_collart.ads_high_value_user_android_Info_ignore`（Google Drive 外表，对应忽略 Sheet）

## 2. 核心作用

1. 给 n8n「Collart 大R播报」做「之前忽略大R」INNER JOIN：原 ignore 表是 Drive 外表，n8n 服务账号 `Permission denied while getting Drive credentials`。
2. 不要用原表 `ads_high_value_user_android_Info_ignore` 替代本表去做 n8n 查询。

## 3. 核心字段

| 字段 | 含义 |
|---|---|
| `user_id` | 忽略名单用户 |
| `app_name` | 端 |
| `country` | 国家 |
| `first_active_Date` | 首次活跃 |
| `last_order_date` | 最近订单日 |
| `total_revenue` | 累计价值（复制时快照） |
| `ignore_times` | 忽略次数；一人一行。首次 1，再忽略 +1；`>=3` 不再进「之前忽略大R」 |

## 4. 口径/红线

- 本表是**快照**，忽略 Sheet 有增删或 `ignore_times` 变更后需要重新复制。
- 「之前忽略大R」：昨天 sexual≥0.3 + 在本表 + `ignore_times < 3` + 不在 `ads_high_value_user_production`。
- 建卡再用忽略 Sheet 交叉确认（活口径以 Sheet 的 `ignore_times` 为准），并排除大R Sheet。
- Google Sheet 与本表字段名均为 `ignore_times`，不要再用 `忽略次数` / `ingnore_times`。
