# `aidata2025.ads_collartandroid.ads_oper_event_metric_attr_di`

## 1. 基础信息

- 表中文名：Collart Android 日×默认维度事件指标
- 粒度：`event_date × is_new × is_vip × country × traffic_src_type × traffic_src_platform × traffic_src_name × app_version`
- 上游：`ads_oper_user_event_metric_di` + `ads_oper_user_active_di`
- 列由 `ads_dim_metric_rule` 热指标驱动（去 `_pv`）

## 2. 核心作用

漏斗按新老 / VIP / 国家 / 渠道 / 版本切分。

## 3. 指标口径

每个热指标一列 `STRUCT<uv, pv>`：

- `uv` = `COUNTIF(UEM列 > 0)`
- `pv` = `SUM(UEM列)`

`app_version` 按当日 active DAU Top5，其余 `'other'`。

## 4. 查询示例

```sql
SELECT event_date, is_new, country, home_show.uv, video_generate_start.pv
FROM `aidata2025.ads_collartandroid.ads_oper_event_metric_attr_di`
WHERE event_date = DATE '2026-08-26';
```

## 5. 数据质量

冷指标不进本表。2026-09-02 与 Sheet 27 个热指标对齐。
