# 表文档模板（ai-knowledge canonical）

> 新建表文档时使用。已有文档保持原有结构，只补缺失章节。

## 文件名

```
{KNOWLEDGE_ROOT}/{project}/tables/{project}.{dataset}.{table}.md
```

示例：`collart_web/tables/aidata2025.ods.orders.md`

---

## 可选 YAML frontmatter（飞书同步表可保留）

从 `_generated/` 迁移时，可保留 metadata 便于对账：

```yaml
---
doc_type: table_knowledge
table_name: aidata2025.dataset.table
table_cn_name: 中文名
projects: ["collart web"]
metadata_status: complete
field_status: available
---
```

手工维护的新表**可不写** frontmatter，除非需要与 Bitable 对账。
