## 记录时间

## 分析背景
Web 大R分析 - 用户价值分层及高价值用户定义

## 数据口径定义（已确认）

### 1. 用户价值计算
| 维度 | 定义 |
|:---|:---|
| 时间范围 | 历史累计（全量数据） |
| 价值定义 | 累计付费金额（美元） |
| 数据来源 | `pubdata2025.dwd.dwd_cdct_revenue_stripe_di`（2026-08-28 起；历史曾用 `ods.orders`。不要用空表 HI） |
| 用户标识 | user_id |
| 产品范围 | 仅 Collart Web |

### 2. 金额计算方式
`sql
-- 美元金额计算
SUM(total_price / exchange_rate / 100)
`
- 汇率表：idata2025.dim.exchange_rate_days
- 关联条件：date(created_at) = stats_date AND lower(currency) = lower(currency)

### 3. 订单状态过滤
`sql
status IN ('active', 'paid', 'active_ending')
`

### 4. 用户分层标准（2026-03-16 确认）
| 用户分层 | 累计付费金额（美元） | 说明 |
|:---|:---|:---|
| 超大R | >= \ | 头部高价值用户 |
| 大R | \ - \ | 高价值用户 |
| 中R | \ - \ | 中等价值用户 |
| 小R | \ - \ | 普通付费用户 |

**大R定义**：>= \（中R + 大R + 超大R）

## SQL 模板

`sql
-- 用户价值分层查询
WITH user_value AS (
  SELECT 
    a.user_id,
    SUM(a.total_price / b.rate / 100) AS total_revenue_usd
  FROM idata2025.ods.orders a
  LEFT JOIN idata2025.dim.exchange_rate_days b 
    ON DATE(a.created_at) = CAST(b.stats_date AS DATE)
    AND LOWER(a.currency) = LOWER(b.currency)
  WHERE a.status IN ('active', 'paid', 'active_ending')
    AND a.user_id IS NOT NULL
  GROUP BY a.user_id
),

user_tier AS (
  SELECT 
    user_id,
    total_revenue_usd,
    CASE 
      WHEN total_revenue_usd >= 500 THEN '超大R'
      WHEN total_revenue_usd >= 100 THEN '大R'
      WHEN total_revenue_usd >= 50 THEN '中R'
      ELSE '小R'
    END AS user_tier
  FROM user_value
)

SELECT 
  user_tier,
  COUNT(DISTINCT user_id) AS user_count,
  ROUND(COUNT(DISTINCT user_id) * 100.0 / SUM(COUNT(DISTINCT user_id)) OVER(), 2) AS user_pct,
  ROUND(SUM(total_revenue_usd), 2) AS tier_revenue,
  ROUND(SUM(total_revenue_usd) * 100.0 / SUM(SUM(total_revenue_usd)) OVER(), 2) AS revenue_pct,
  ROUND(AVG(total_revenue_usd), 2) AS avg_revenue
FROM user_tier
GROUP BY user_tier
ORDER BY avg_revenue DESC;
`

## 备注
- stripe_di 表适合统计收入，但无 user_id 粒度
- 用户粒度分析必须使用 orders 表
