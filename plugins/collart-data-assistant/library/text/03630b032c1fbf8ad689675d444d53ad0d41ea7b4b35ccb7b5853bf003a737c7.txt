# 表名：aidata2025.ads_collart.big_r_realtime_today_income

## 1. 基础信息

- 中文名：Collart 当天准实时用户收入表
- 表类型：用户粒度中间表
- 行粒度：北京时间当天每个 `app_name + user_id` 一行
- 逻辑主键：`app_name + user_id`
- 上游：Android/iOS GA4 `in_app_purchase`、Web `ods.orders`

## 2. 核心作用

为大R准实时播报提供当天收入。n8n 将本表 `total_value`
与 T+1 ADS 高价值用户表的历史 `value` 相加，得到当前累计价值。

## 3. 核心字段

| 字段 | 含义 |
|---|---|
| `user_id` | Collart 用户 ID |
| `app_name` | `collart-android`、`vidart-ios`、`collart-web` |
| `total_value` | 北京时间当天累计收入，美元 |
| `country` | 用户国家；无法识别时为 `unknown` |

## 4. 口径红线

- ADS `value` 必须不包含当天收入，否则与本表相加会重复计算。
- Web 收入只统计 `status IN ('active','paid','active_ending')`。
- Android/iOS 收入使用 GA4 `in_app_purchase.event_value_in_usd`。
- 本表是当天快照，不跨天累计。
