## 本机挂载（Cursor + Codex）

将下面的 `SKILL_DIR` 换成你机器上该文件夹的实际绝对路径。

### Windows（管理员 CMD 或已开开发者模式）

```bat
set SKILL_DIR=C:\Users\<你>\OneDrive\cursor-sync\collart-agent-skills\collart-biz-analysis

mkdir %USERPROFILE%\.cursor\skills 2>nul
mkdir %USERPROFILE%\.codex\skills 2>nul

mklink /J %USERPROFILE%\.cursor\skills\collart-biz-analysis %SKILL_DIR%
mklink /J %USERPROFILE%\.codex\skills\collart-biz-analysis %SKILL_DIR%
```

### 验证

新开 Cursor / Codex 对话，问：

> 用 collart 分析 skill 看一下 Android 近 7 日 DAU

Agent 应读取本包 `SKILL.md` / `table-routing.md`，并查 `aidata2025.ads_collartandroid.ads_oper_basic_indicator_daily_di`。
