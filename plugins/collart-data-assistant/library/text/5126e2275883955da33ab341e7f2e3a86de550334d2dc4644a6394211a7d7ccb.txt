## 2026-03/04 历史方法

2026-03-23 的旧文档推荐旧 ADS 聚合 / DWD 用户计数，旧 SQL 写 dt/user_id；这些表达需与当前字段和用户键对应，不能直接运行。

日聚合数相加前核对维度互斥，避免用户跨国家、渠道或版本重复。设备伪 ID 与登录 user_id 不可混为一套去重键。
