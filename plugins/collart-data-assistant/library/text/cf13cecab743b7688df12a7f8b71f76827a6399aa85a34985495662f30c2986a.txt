# 📈 指标档案：USER_SEGMENTATION (Web)

## 1. 基本定义与业务口径
## 大R定义

累计付费金额 >= \ 美元的用户

---

## 内部分层标准

| 层级 | 金额标准 | 说明 |
|:---|:---|:---|
| 超大R | >= \ | 头部高价值用户，需重点维护 |
| 大R | \-\ | 高价值用户，关注留存和复购 |
| 中R | \-\ | 中等价值用户，可培育成大R |
| 小R | \-\ | 大R门槛，需关注转化 |

---

## 分层逻辑

基于 Collart Web 实际数据分布（2026-03-15 数据参考）：
- **小R占比 78%**：是大R用户的主要组成部分
- **中R仅 13人**：呈现明显断层，需重点运营关注
- **超大R 1人贡献了 62% 的大R收入**：呈现头部效应

## SQL模板

`sql
-- 大R用户分层查询
WITH user_value AS (
  SELECT 
    user_id,
    SUM(total_price / rate / 100) AS total_revenue_usd
  FROM idata2025.ods.orders a
  LEFT JOIN idata2025.dim.exchange_rate_days b 
    ON DATE(a.created_at) = CAST(b.stats_date AS DATE)
    AND LOWER(a.currency) = LOWER(b.currency)
  WHERE status IN ('active', 'paid', 'active_ending')
    AND user_id IS NOT NULL
  GROUP BY user_id
  HAVING total_revenue_usd >= 50
),

whale_users AS (
  SELECT 
    user_id,
    total_revenue_usd,
    CASE 
      WHEN total_revenue_usd >= 500 THEN '超大R'
      WHEN total_revenue_usd >= 200 THEN '大R'
      WHEN total_revenue_usd >= 100 THEN '中R'
      ELSE '小R'
    END AS tier
  FROM user_value
)

SELECT 
  tier,
  COUNT(*) AS user_count,
  ROUND(AVG(total_revenue_usd), 2) AS avg_revenue,
  ROUND(SUM(total_revenue_usd), 2) AS total_revenue
FROM whale_users
GROUP BY tier
ORDER BY avg_revenue DESC;
`
