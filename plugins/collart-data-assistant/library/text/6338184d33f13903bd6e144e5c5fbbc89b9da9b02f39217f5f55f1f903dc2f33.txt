# Collart Fashion 项目配置

## 产品范围

- **产品**：Collart Fashion（服装带货 / AI Fashion Video）
- **当前生成器**：[`https://collart.ai/en/studio/ai-fashion-video`](https://collart.ai/en/studio/ai-fashion-video)
- **官方营销页**：[`https://collart.ai/en/ai-fashion-video`](https://collart.ai/en/ai-fashion-video)
- **当前核心流程**：Reference Video → Model → Clothing → Output Settings → AI Service → Download / Pay
- **数据底座**：与 Collart Web 共用 GA4 埋点与订单表
- **产品知识**：[`ai_fashion_video_product.md`](ai_fashion_video_product.md)
- **埋点文档**：[`fashion_tracking_events.md`](fashion_tracking_events.md)（飞书 Collart 项目埋点2026 / sheet `PIvKn2`）
- **漏斗 Playbook**：[`../analysis_playbooks/fashion_video_funnel.md`](../analysis_playbooks/fashion_video_funnel.md)
- **默认分析用户**：Fashion 用户（见 [`../indicators/fashion_vs_main_site_user.md`](../indicators/fashion_vs_main_site_user.md)）

## 用户划分规则

| 站点 | events（`page_location`） | 加工表（`package_name`） |
|---|---|---|
| 主站 | 不含 `studio` / `fashion` | ADS：`'collart_web'`（旧表曾写 `collartweb`） |
| 服装带货（Fashion） | 含 `studio` 或 `fashion` | `'collart_fashion'` |

## 数据表默认范围

| 类型 | 默认表 |
|:---|:---|
| 用户粒度收入 | `pubdata2025.dwd.dwd_cdct_revenue_stripe_di` 或 `ads_collartfashion.ads_oper_user_active_di.revenue`（不要 `ods.orders`） |
| 投放花费 | country `delivery` 仍硬编码 0，专项未接；不要自行扫 ODS facebook |
| 用户特征 | `aidata2025.ads_collart.ads_oper_user_new_collartweb_di` |
| 事件数据 | `storytemplate-10a27.analytics_232977577.events_*` |

## 默认过滤条件

- **Web 端过滤**：`app_info.id IS NULL`（events 原始表）。
- **Fashion 默认范围**：加工表用 `package_name = 'collart_fashion'`；events 用 `page_location` 含 `studio` / `fashion` 的用户范围。
- **AI 服务**：Fashion Video 服务链路增加 `service_type = 'fashion_video'`。
- **VIP**：Fashion 付费入口增加 `from = 'fashion_video'`。
- **内部用户过滤**：见 [`../analysis_playbooks/internal_user_filter.md`](../analysis_playbooks/internal_user_filter.md)。

## 来源优先级

1. 当前产品界面：判断实际步骤、可见选项与交互。
2. 飞书埋点表：判断标准事件名、参数名和业务注释。
3. GA4 / 数仓验数：判断事件是否真实触发、参数枚举、转化和收入。
4. 官网营销页：仅用于产品定位与外部主张，不作为已验证经营指标。

产品界面与埋点表冲突时，两者都记录，并在 GA4 中验数后再收敛口径；不能把产品界面文案直接推断成已上报事件。

## BigQuery 凭证

- **默认**：`aidata2025`（见 `0global/service-accounts/credential_index.json`）。
