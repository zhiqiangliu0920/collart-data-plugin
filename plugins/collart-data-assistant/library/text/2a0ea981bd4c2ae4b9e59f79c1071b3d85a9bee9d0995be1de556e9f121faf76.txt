# Web DAU：活跃口径与历史定义

> 文档依据与历史范围如下；本轮为正文静态整理，未重跑指标查询。

日活跃用户按自然日、业务产品及明确的用户键去重，新老用户均可计入；不要求必须登录。当前查数先按 [公司 ADS 红线](../../1company/analysis_playbooks/collart_ads_redlines.md) 选择用户日 active / 日报入口；读取 active 时按 `is_active` 计活跃，排除仅收入骨架行。

Web 主站与 Fashion 必须按业务归属分开；用户已确认旧 DWD 和 ADS Web 用户表废弃，见 [旧表替代说明](../tables/dwd_oper_user_collartweb_di.md)。

## 2026-03/04 历史方法

2026-03/04 的旧文档将 session_start 的 user_pseudo_id UV 称作 DAU，并以 app_info.id IS NULL 过滤；保留为历史“会话启动 UV”，不能覆盖当前经营 DAU，也不足以识别主站。

日聚合数相加前核对维度互斥，避免用户跨国家、渠道或版本重复。设备伪 ID 与登录 user_id 不可混为一套去重键。
