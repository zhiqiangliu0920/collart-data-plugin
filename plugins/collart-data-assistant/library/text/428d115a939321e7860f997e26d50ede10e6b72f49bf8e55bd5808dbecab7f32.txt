# Web 留存：cohort 与完整观察窗

> 文档依据与历史范围如下；本轮为正文静态整理，未重跑指标查询。

先区分新增留存与活跃回访。新增留存的 cohort 是指定日新用户，活跃回访的 cohort 是指定日活跃用户；两者分母不同。D1 定义为 cohort_date + 1 的回访，D7/D30 类推；这是分析日偏移定义，不推定旧 retain_N 字段也按相同后缀命名。

`留存率 = cohort 中在目标日仍活跃的去重用户数 / cohort 去重用户数`。同一产品、用户键和活跃口径保持一致，分母为 0 时留空。补零回访 cohort；只比较拥有完整 N 日观察的 cohort，不把未到观察期当流失。跨 cohort 汇总按人数加权。

## 数据与历史限制

当前活跃规则见 [DAU](dau.md)，日报日期和成熟窗口见 [公司日期口径](../../1company/indicators/collart_daily_report_date_windows.md)。旧表中的 retain_2、retain_7 与 Dn 的对应需按加工定义核查，不从自动生成字段说明推定。

旧 SQL 以有界 2026-03 窗口 MIN(session_start 日期) 为首日，只能称窗口首次观察，不能称首次新增；月底 cohort 缺少完整 D30。 原脚本的日期和事件方式已吸收到本页，旧 SQL 退出默认入口。
