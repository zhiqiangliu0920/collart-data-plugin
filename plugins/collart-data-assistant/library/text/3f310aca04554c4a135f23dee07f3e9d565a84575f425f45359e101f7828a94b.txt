# `aidata2025.ads_collartfashion.ads_oper_user_revenue_di`

## 1. 基础信息

- 中文名：Fashion Stripe 订单明细
- 表类型：ADS 订单事实表
- 行粒度：1 笔 Stripe 订单（`transaction_id` 去重）
- 分区：`event_date`
- 更新：T+1；Dataform 任务名 `ads_oper_user_revenue_di`
- 生效：2026-09-09
- 上游：`pubdata2025.dwd.dwd_cdct_revenue_stripe_di` + Fashion `vip_subscribe_succeed` 归属

## 2. 核心作用

- Fashion 收入金额真值（字段名 `revneue`，不要改成 revenue）。
- 用户日收入由 `ads_oper_user_active_di` 按 `event_date × user_id` 汇总后写入，不再单独做日收入表。

## 3. 口径 / 红线

- 只保留能对上 Fashion 的订单：同一 `user_id`，前后 10 分钟最近一条 `vip_subscribe_succeed`，且事件 `package_name = collart_fashion`。
- 排除内部账号。
- Stripe 源上的 `app_name` 多为 `collart_web`；ADS 归属包名是 `collart_fashion`。
- 旧用户日表 `ads_collart.ads_oper_user_revenue_collart_fashion_di` 已停更。

## 7. 示例 SQL

```sql
SELECT event_date, transaction_id, user_id, product_name, description_type, revneue
FROM `aidata2025.ads_collartfashion.ads_oper_user_revenue_di`
WHERE event_date BETWEEN DATE '2026-07-11' AND DATE '2026-09-08'
```
