# 📈 指标档案：DAU (Web)

## 1. 基本定义与业务口径
## 口径定义

日活跃用户：当日至少触发一次 `session_start` 事件的去重用户数。

## 计算逻辑

| 要素 | 说明 |
|------|------|
| 事件名 | `session_start` |
| 过滤条件 | `app_info.id IS NULL` |
| 去重字段 | `user_pseudo_id` |
| 时间粒度 | 自然日（event_date） |

## 业务口径

- 包含所有活跃用户（新老用户都算）
- 按设备去重（user_pseudo_id）
- 不区分登录状态
