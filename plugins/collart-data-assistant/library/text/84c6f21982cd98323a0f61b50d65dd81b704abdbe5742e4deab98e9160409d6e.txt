# 📈 指标档案：CONVERSION (Android)

## 1. 基本定义与业务口径
## 口径定义

订阅转化率：完成订阅购买的用户数占总活跃用户的比例。

## 计算逻辑

| 要素 | 说明 |
|------|------|
| 付费事件 | `vip_subscribe_succeed` |
| 分母 | DAU（`session_start` 去重用户数） |
| 可选参数 | `product_id`（订阅商品ID） |

## 付费模式

- 新用户注册赠送30点数
- 点数用完引导订阅
- 订阅后每周赠送点数
- 赠送点数用完引导购买点数包
