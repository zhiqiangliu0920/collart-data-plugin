# 表名：aidata2025.ads_collart.big_r_realtime_alert_log

> 文档整理：2026-09-12；业务状态：documented；复核：reviewed_static。原业务日期见正文，本次未重新查询生产数据。


## 1. 基础信息

- 中文名：Collart 大R准实时播报成功日志
- 表类型：辅助状态表
- 行粒度：每个 `app_name + user_id` 一行
- 逻辑主键：`app_name + user_id`
- 写入方：n8n `Collart 大R准实时播报`

## 2. 核心作用

记录已经成功发送过准实时大R卡片的用户，防止每 5 分钟重复播报。
Web 用户从 50 档升到 100 档仍视为同一用户，不产生第二次播报。

## 3. 核心字段

| 字段 | 含义 |
|---|---|
| `user_id` | Collart 用户 ID |
| `app_name` | `collart-android`、`vidart-ios`、`collart-web` |
| `first_sent_at` | 首次成功发送卡片时间 |
| `last_total_value` | 最近一次成功发送时的累计价值 |
| `source` | 写入来源，当前为 `n8n_realtime_card` |
| `updated_at` | 最近更新时间 |

## 4. 口径红线

- 去重键禁止加入 Web 价值档位，否则 50 升 100 会重复播报。
- 只在飞书卡片实际发送成功后写入。
- 自动入表状态以大R Google Sheet 为准，本表只负责播报去重。
