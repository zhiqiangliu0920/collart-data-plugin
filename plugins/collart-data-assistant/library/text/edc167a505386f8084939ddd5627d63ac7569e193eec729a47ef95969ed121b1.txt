### 默认过滤条件
- **Web 端过滤**: `app_info.id IS NULL`
- **内部用户过滤**: 后续所有 Collart Web 统计分析必须排除内部 `user_id`，清单见 [`analysis_playbooks/internal_user_filter.md`](../../1company/analysis_playbooks/internal_user_filter.md)，SQL 片段见 [`sql_presets/internal_user_filter.sql`](../sql_presets/internal_user_filter.sql)
- **Fashion / 主站用户划分**:
  - **events 原始表**：`page_location` 含 `studio` 或 `fashion` → Fashion；否则 → 主站
  - **DWD/ADS 加工表**：`package_name = 'collart_web'` → 主站；`package_name = 'collart_fashion'` → 服装带货
  - 详见 [`indicators/fashion_vs_main_site_user.md`](../indicators/fashion_vs_main_site_user.md)，SQL 片段见 [`sql_presets/fashion_vs_main_site_user.sql`](../sql_presets/fashion_vs_main_site_user.sql)
