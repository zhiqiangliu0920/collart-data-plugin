# `aidata2025.ads_collartandroid.ads_oper_event_metric_country_di`

> 文档整理：2026-09-12；业务状态：documented；复核：reviewed_static。原业务日期见正文，本次未重新查询生产数据。


## 1. 基础信息

- 表中文名：Collart Android 日×国家事件指标
- 粒度：`event_date × country`（全量国家）
- 上游：`ads_oper_event_metric_attr_di` 按 country SUM

## 2. 核心作用

事件漏斗国家看板。与 `ads_oper_basic_indicator_country_di` 并行（后者管 DAU/收入/花费）。

## 3. 指标口径

热指标 `STRUCT<uv, pv>` = attr 同列按国家求和。部分漏斗 STRUCT 内另有 `new_uv` / `vip_uv` 等切片，**不由 Sheet 驱动**。

## 4. 查询示例

```sql
SELECT event_date, country, home_show.uv, video_generate_start.pv
FROM `aidata2025.ads_collartandroid.ads_oper_event_metric_country_di`
WHERE event_date = DATE '2026-08-26'
ORDER BY home_show.uv DESC;
```
