## 查询前确认

1. 明确产品、年份、起止日期、时区，以及是否只使用完整日；不沿用示例中的固定日期。
2. 写清统计对象和粒度：事件行、用户、订单、会话或任务；选择对应去重键。
3. 先查项目 `tables/`、`indicators/`、`product/` 和 `sql_presets/`，核对表是否仍有效、分区是否齐全。项目没有 `sql_standards/` 时，不假定它存在。
4. 区分当前规则、历史版本和待复核事项。项目特有过滤与共用定义同时说明；遇到冲突，按明确授权和有效来源处理，不能仅凭目录层级或更新时间覆盖全局约束。

## 执行约束

### 日期与数据裁剪

- **团队既有规则：每次查询 GA4 `events*` 原始分片表覆盖的日历日期不超过 30 天（含首尾）。** 这是本知识库的成本控制约定，不是 BigQuery 产品自身的硬上限。更长区间需要使用合适的汇总表，或在任务授权范围内分段处理并正确合并去重口径。
- `events_*` 是多张日期分片表。必须用 `_TABLE_SUFFIX` 限定实际扫描表范围；不能只写 `event_date` 条件来代替它。官方要求裁剪条件可作为常量表达式求值；最终日期和 dry run 扫描估算要一致。[通配表过滤](https://docs.cloud.google.com/bigquery/docs/querying-wildcard-tables#filter_selected_tables_using_table_suffix)
- 普通分区表应过滤其实际分区列。按摄入时间分区的表才使用相应伪列；`_PARTITIONDATE` 对应日粒度摄入时间分区，不能假定任意分区表都有这个字段。[分区表过滤](https://docs.cloud.google.com/bigquery/docs/querying-partitioned-tables)
- `events_YYYYMMDD` 与 `events_intraday_YYYYMMDD` 的范围分别明确，避免重复计数或把未完成日混入完整日。具体保留策略按任务的现有证据确认。

### 产品、身份与指标

- 查询 GA4 Web 数据沿用 `app_info.id IS NULL`。该条件用于区分 Web/App 数据；Web 与 Fashion 的业务归属仍须采用项目文档中的产品过滤，不能只凭此条件区分两者。
- `COUNTIF(condition)` 是满足条件的行数；条件 UV 用 `COUNT(DISTINCT IF(condition, identity, NULL))`。`user_id`、`user_pseudo_id`、会话键和任务键各有适用范围，不能直接互换。
- 多事件 PV/UV 的比值只说明同一窗口内的计数关系。未建立同一批用户、发生顺序和必要关联键时，不能称为严格漏斗转化率或任务成功率。
- 收入口径须明确币种、金额单位、成功支付状态、退款及统计时点；付款入口事件不能替代成功付款证据。具体定义引用项目 `indicators/`，不在 SQL 全局文档重复设定。
- 字段缺失、零值、空集合、未覆盖和无权限是不同状态；`COALESCE(..., 0)` 仅在业务定义允许时使用。

### 成本与副作用

- 在同一数据范围、同一统计粒度下，优先考虑条件聚合和一次提取参数，以降低重复逻辑；实际扫描量与性能以执行计划、dry run 或任务统计为准，不承诺固定加速倍数。
- 按需选择列，尽早过滤。CTE 主要用于组织逻辑，不能保证结果只计算一次；需要复用中间结果时，评估变量、临时表及其额外成本。[查询计算优化](https://docs.cloud.google.com/bigquery/docs/best-practices-performance-compute)
- 大表执行前按既有任务要求估算扫描量并遵守预算。本文不规定新的统一金额上限，也不改变已授权任务的执行权限。
- `CREATE`、`MERGE`、`UPDATE`、回填、恢复表、克隆及购买 BI Engine 容量都可能改变数据或配置。历史示例不是执行授权；只在对应任务明确授权后使用。本次文档整合未执行这些操作。

## 分析与交付流程

| 步骤 | 要说明的内容 |
|---|---|
| 定义 | 业务问题、产品、日期、时区、粒度、分子与分母 |
| 取数 | 表来源、过滤、去重、关联条件、参数和扫描范围 |
| 检查 | 数据覆盖、重复行、空值、单位、分区及异常限制 |
| 解释 | 证据支持的结论、推断以及尚不能确定的部分 |
| 交付 | 结论与结果表、SQL、文件位置、口径、数据日期和限制 |

正式分析保留 SQL 和必要证据；临时查看按当前工作区约定保存或引用，不强制把每次临时输出都纳入共享知识库。个人原始明细、凭证及运行配置不放入插件。
