# 表名：aidata2025.ads_collart.ads_oper_user_new_collartweb_di

> 文档整理：2026-09-12；业务状态：documented；复核：reviewed_static。原业务日期见正文，本次未重新查询生产数据。


## 1. 基础信息
- 表中文名：collart web产品新增用户表
- 表类型：事实表
- 表描述：统计每天每天新访问用户的基本信息，与aidata2025.dwd.dwd_oper_user_collartweb_di字段基本相同，只做过滤is_new=true处理
- 行粒度：每天每个 `user_pseudo_id` 1 行
- 主键字段：`user_Pseudo_id`
- 分区字段：event_date
- 更新频率：每日北京时间8点左右自动更新
- 上游来源：aidata2025.dwd.dwd_oper_user_collartweb_di
- 优先级：高
- 成本效率：低

## 2. 核心作用
本表主要用于以下场景：
1. 关联events_*表中user_pseudo_id，获取新用户国家、设备、渠道等信息
2. 计算新增、新用户留存等指标时使用
3. 分析新用户的国家、设备、渠道分布时使用

## 3. 核心字段
字段名：event_date
- 类型：DATE
- 字段角色：时间维度 / 分区字段
- 业务含义：事件发生日期，用于标识用户行为发生的自然日期
- 注意：通常用于按天统计指标，如 DAU、PV、生成次数等；查询时建议结合 _TABLE_SUFFIX 控制扫描范围

字段名：app_name
- 类型：STRING
- 字段角色：产品维度
- 业务含义：产品名称，用于区分不同应用或产品线
- 注意：在多产品分析场景中用于区分不同产品的数据

字段名：user_pseudo_id
-类型：STRING
-字段角色：用户标识 / 用户维度
-业务含义：匿名用户唯一标识，用于识别同一设备或浏览器的用户行为
-注意：常用于用户去重（如 UV、DAU）；同一用户跨设备可能生成不同 ID

字段名：user_id
-类型：STRING
-字段角色：用户标识
-业务含义：业务系统中的用户账号 ID，通常在用户登录后才会存在
-注意：未登录用户该字段可能为空；做用户分析时需与 user_pseudo_id 区分

字段名：package_name
-类型：STRING
-字段角色：产品标识 / 站点划分
-业务含义：Web 产品线标识。`collartweb` = Collart Web 主站；`collart_fashion` = 服装带货（Fashion）站点
-注意：Collart Fashion 分析默认 `package_name = 'collart_fashion'`；主站分析用 `collartweb`。数仓实际枚举见 [`../../collart_web/indicators/fashion_vs_main_site_user.md`](../../collart_web/indicators/fashion_vs_main_site_user.md)

字段名：traffic_src_name
-类型：STRING
-字段角色：流量来源维度
-业务含义：流量来源名称，如某个广告渠道、活动入口或推广渠道
-注意：用于流量归因分析

字段名：traffic_src_source
-类型：STRING
-字段角色：流量来源维度
-业务含义：流量来源渠道，如 google、facebook、direct 等
-注意：用于渠道分析、投放效果分析

字段名：traffic_src_type
-类型：STRING
-字段角色：流量类型维度
-业务含义：流量类型分类，取值：organic（自然流量）、delivery（投放流量）、inhouse（内部流量）
-注意：可用于区分自然流量与广告流量

字段名：country
-类型：STRING
-字段角色：地理维度
-业务含义：用户所在国家或地区
-注意：用于国家分布分析、区域增长分析、国家付费能力分析

字段名：device_language
-类型：STRING
-字段角色：设备维度
-业务含义：用户设备系统语言
-注意：通常用于多语言产品的用户语言分布分析

字段名：device_category
-类型：STRING
-字段角色：设备维度
-业务含义：设备类型，例如 mobile、tablet、desktop
-注意：用于分析不同设备类型用户行为差异

字段名：mobile_brand_name
-类型：STRING
-字段角色：设备维度
-业务含义：移动设备品牌名称，例如 Apple、Samsung、Huawei 等
-注意：仅在移动设备场景下存在

字段名：mobile_marketing_name
-类型：STRING
-字段角色：设备维度
-业务含义：设备型号名称，例如 iPhone 14、Galaxy S23 等
-注意：用于设备型号分布分析

字段名：operating_system
-类型：STRING
-字段角色：设备维度
-业务含义：设备操作系统，例如 iOS、Android、Windows、MacOS 等
-注意：用于不同系统用户行为差异分析

字段名：operating_system_version
-类型：STRING
-字段角色：设备维度
-业务含义：设备操作系统版本号
-注意：用于系统版本分布分析、兼容性问题排查

字段名：browser
-类型：STRING
-字段角色：设备维度
-业务含义：用户访问网站时使用的浏览器类型，例如 Chrome、Safari、Edge 等
-注意：用于浏览器兼容性分析

字段名：is_vip
-类型：BOOLEAN
-字段角色：用户属性
-业务含义：用户是否为 VIP 订阅用户
-注意：用于付费用户分析，如 VIP 用户行为、付费转化率等

字段名：is_login
-类型：BOOLEAN
-字段角色：用户状态属性
-业务含义：用户当前是否处于登录状态
-注意：用于区分登录用户与匿名用户的行为差异

## 6. 数据质量与风险提示

- 本表 `event_date` 为 `dwd_oper_user_collartweb_di` 中 `is_new=true` 的过滤结果，上游与 `first_visit` 存在耦合。
- **分析推荐口径**：以 `user_pseudo_id` 首次发现日为准，见 [`../indicators/new_user_pseudo_id.md`](../indicators/new_user_pseudo_id.md) 与 [`../sql_presets/new_user_by_pseudo_id.sql`](../sql_presets/new_user_by_pseudo_id.sql)。
- 本表仍可用于快速关联国家/设备/渠道字段，但与 pseudo 首次发现口径不一致时**优先 pseudo 口径**。
