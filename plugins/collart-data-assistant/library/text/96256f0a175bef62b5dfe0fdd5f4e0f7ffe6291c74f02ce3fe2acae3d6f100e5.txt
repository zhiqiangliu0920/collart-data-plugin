# Collart Fashion 服装带货埋点

> 权威来源：飞书 Wiki [Collart 项目埋点2026](https://cwtus1pn64.feishu.cn/wiki/DpcRwAuBSiSmaZkiIxWc62gxnhf?sheet=PIvKn2)（sheet：`PIvKn2`，子表：`collart web服装带货埋点`）  
> 同步时间：2026-08-18；同步范围：`A1:F51`；事件数：47  
> 产品核对：[Fashion Generator](https://collart.ai/en/studio/ai-fashion-video)

Collart Fashion 与 Collart Web 共用 GA4 事件表。本文件记录 Fashion 专属事件，以及复用 Web 埋点时新增的 Fashion 参数值。事件名和参数拼写以源表原文为准；源表中的疑似错拼不会在查询中擅自修正。

## 当前产品流程

| 步骤 | 当前界面 | 主要输入 | 对应埋点 |
|---|---|---|---|
| Step 1 | Select Reference Video | 预设参考视频、上传视频、视频链接；可选提示词微调与自定义场景图 | `fashion_generator_show`、`fashion_reference_video_*`、`fashion_upload_video_*` |
| Step 2 | Pick a Model | Preset / History / Upload | `fashion_model_category_show`、`fashion_model_*` |
| Step 3 | Add Clothing | 上传服装、商品链接导入、多套 Outfit | `fashion_outfit_*` |
| Step 4 | Output Settings | 背景音乐、分辨率、视频模型 | `fashion_video_generate_click` |

当前界面已是四步流程。2026-07-22 旧版文档中的“模特 → 服装 → 参考视频/生成”顺序不再适用。

## 与 2026-07-22 版本相比

- 流程从三步改为四步，参考视频移到 Step 1，生成移到 Step 4。
- 新增 `fashion_reference_video_show`、`fashion_reference_video_link_confirm`、`fashion_reference_video_link_success`。
- 新增 `fashion_model_category_show`、`fashion_outfit_link_notify`、`credit_pack_purchase`。
- `fashion_video_generate_click` 新增 `video_model` 参数。
- 当前源表已移除旧事件 `fashion_inspiration_view_more`；除非 GA4 实际仍有数据，否则不再放入标准漏斗。
- 源表第六列“最新更新内容”在本次同步范围内无非空内容。

## 已知埋点缺口与验数红线

1. `fashion_generator_show.step` 只写 `1/2/3`，但当前界面存在 Step 4；按步骤分析前先检查实际枚举。
2. 参考视频预设模板的“选中”动作没有独立事件；不能用模板曝光替代模板选择。
3. 商品链接导入只有 `fashion_outfit_link_notify`，未记录平台、confirm、success/fail；暂时无法评估各平台导入成功率。
4. BGM、分辨率、视频模型没有单独交互事件，只能使用 Generate 点击时快照参数分析最终选择。
5. `fashion_aesset_click`、`presrt_id` 为源表拼写；SQL 必须先按原值验数，不得静默纠错。
6. 服务失败事件未在本表定义错误码/失败原因；失败归因需要再查公共参数或服务日志。
