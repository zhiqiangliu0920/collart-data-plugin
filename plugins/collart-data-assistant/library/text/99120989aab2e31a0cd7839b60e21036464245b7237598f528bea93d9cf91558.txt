# 指标：Fashion 用户 vs 主站用户

## 1. 业务定义（Collart Fashion 默认口径）

Collart Fashion（服装带货）与 Collart Web 主站共用 Web 埋点。Fashion 项目分析时，默认只关心 **Fashion 用户**；与主站的边界如下：

### 方式 A：原始埋点表（`events_*`）

| 用户类型 | 判定条件 |
|---|---|
| **Fashion 用户** | 任意 `page_location` 包含 `studio` 或 `fashion`（不区分大小写） |
| **主站用户** | 进入 Web 埋点但 **从未** 出现上述 `page_location` |

### 方式 B：加工表（含 `package_name` 字段的 DWD / ADS）

| 站点                | `package_name`（数仓实际值） |
| ----------------- | ------------------- |
| **主站**            | `'collartweb'`      |
| **服装带货（Fashion）** | `'collart_fashion'` |

**Fashion 项目默认范围：** 统计分析默认 **仅包含 Fashion**（加工表用 `package_name = 'collart_fashion'`；events 用方式 A），除非任务明确要求对比主站或全站 Web 用户。

**Fashion 新用户 cohort（推荐）：** 用本表 `ads_oper_user_new_collartweb_di` + `package_name = 'collart_fashion'` + `event_date`，见 [`fashion_new_user.md`](./fashion_new_user.md)。勿用 `first_visit` + `page_location` 替代。

## 2. 字段与数据源

| 要素 | 说明 |
|---|---|
| 主键 | `user_pseudo_id` |
| 原始埋点判定 | GA4 `event_params.page_location` |
| 加工表判定 | `package_name = 'collart_fashion'`（Fashion）；`'collartweb'`（主站） |
| 原始表 | `storytemplate-10a27.analytics_232977577.events_*` |
| 加工表示例 | `dwd_oper_user_event_di`、`dwd_oper_user_collartweb_di`、`ads_oper_user_new_collartweb_di` 等 |
| Web 过滤 | `app_info.id IS NULL`（仅 events） |
| 内部用户 | 必须排除，见 [`../analysis_playbooks/internal_user_filter.md`](../analysis_playbooks/internal_user_filter.md) |

## 3. SQL 模板

### 3.1 加工表（推荐，Fashion 默认）

```sql
WHERE package_name = 'collart_fashion'
```

### 3.2 原始 events（`page_location`）

```sql
WITH user_pages AS (
  SELECT
    user_pseudo_id,
    LOWER((
      SELECT ep.value.string_value
      FROM UNNEST(event_params) ep
      WHERE ep.key = 'page_location'
    )) AS page_location
  FROM `storytemplate-10a27.analytics_232977577.events_*`
  WHERE app_info.id IS NULL
    AND _TABLE_SUFFIX BETWEEN @start_suffix AND @end_suffix
),
fashion_users AS (
  SELECT DISTINCT user_pseudo_id
  FROM user_pages
  WHERE REGEXP_CONTAINS(COALESCE(page_location, ''), r'(studio|fashion)')
)
SELECT * FROM fashion_users;
```

可复用 preset（与 Collart Web 共用）：[`../../collart_web/sql_presets/fashion_vs_main_site_user.sql`](../../collart_web/sql_presets/fashion_vs_main_site_user.sql)
