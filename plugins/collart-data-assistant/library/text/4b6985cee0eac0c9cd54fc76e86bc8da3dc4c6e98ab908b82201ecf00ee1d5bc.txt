## 全局过滤规则

- Web 端分析默认过滤：`app_info.id IS NULL`
- 内部用户过滤：后续所有 Collart Web 统计分析必须排除内部 `user_id`，详见 [`../analysis_playbooks/internal_user_filter.md`](../analysis_playbooks/internal_user_filter.md)
- Fashion / 主站划分：events 用 `page_location`（含 `studio`/`fashion` → Fashion）；加工表用 `package_name`（`collart_web` / `collart_fashion`），详见 [`fashion_vs_main_site_user.md`](./fashion_vs_main_site_user.md)
