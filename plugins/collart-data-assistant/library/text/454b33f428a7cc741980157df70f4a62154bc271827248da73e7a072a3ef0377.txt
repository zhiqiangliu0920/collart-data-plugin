# Web 页面转化：范围、交集与顺序

> 文档依据与历史范围如下；本轮为正文静态整理，未重跑指标查询。

页面 A → B 的转化需要先定义 A/B 的页面或功能进入事件、同一用户/会话、允许耗时，并按事件时间保证 A 在 B 之前。原候选链路为首页 → AI Video 页 → 创建任务 → 生成成功；每一步的实际进入/成功事件应从产品事件字典验证，曝光不能代替进入。

原 2026-03/04 查询只用 page_view 定义 home_visitors，没有首页 URL 过滤，再与同窗 aivideo_edit_show 用户相交。它计算的是两类事件同窗交集，不能称已验证的首页到视频转化。`app_info.id IS NULL` 还需结合主站/Fashion 归属。

无顺序的触达分析与严格漏斗分别报告。会话、国家和渠道拆解见 [会话漏斗诊断](../analysis_playbooks/session_funnel_diagnosis.md)；不沿用旧模板的固定 ±5% 告警值。
