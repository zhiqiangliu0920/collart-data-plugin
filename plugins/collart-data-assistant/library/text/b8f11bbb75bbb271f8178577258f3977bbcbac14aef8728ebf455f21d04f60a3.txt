  # 表名：pubdata2025.dwd.dwd_cdct_revenue_stripe_di

## 1. 基础信息
- 表中文名：collart web产品订单记录表(支付平台)
- 表类型：事实表
- 表描述：每个用户每一笔订单的记录
- 行粒度：订单粒度，transaction_id
- 分区字段：event_date
- 更新频率：每日北京时间8点左右自动更新
- 上游来源：支付平台api拉取
- 优先级：高
- 成本效率：低

## 2. 核心作用
本表主要用于以下场景：
- 计算每日收入、首次订阅收入、点数包收入、续订收入使用
- 分析收入的国家分布
- **2026-08-28 起**：Web 用户粒度收入、移动端俄罗斯支付（`currency='RUB'`）用户粒度收入的 T+1 真值。不再用 `ods.orders`。
- **2026-09-06**：Android/iOS `ads_oper_user_active_di` 已叠加本表 RUB（进 `purchase_revenue`/`credit_revenue`）；四端 profile 都是 `SUM(active.revenue)`。country/daily 未改。
- **2026-09-07**：`dwd_cdct_orders_revenue_hi` 是空表，不要当当天补洞源。

## 3. 核心字段
字段名：event_date
- 类型：DATE
- 字段角色：时间维度 / 分区字段
- 业务含义：订单发生日期，用于标识用户行为发生的自然日期

字段名：description_type
- 类型：string
- 字段角色：订单是首次订阅（Subscription creation）、续订（Subscription update）还是点数包收入（credit）

字段名：revneue
- 类型：bignumeric
- 字段角色：订单价格
- 业务含义：订单价格



## 4. 口径/红线（2026-08-28）

- 不要默认 `app_name='collart_web'`：表内还有 `collart_android`、`vidart`（输出写成 `vidart-ios`）。
- `revneue` 是实收美元（字段名拼写如此）；`pending`/`available` 是打款状态，不是未支付。
- 用户侧美元标价：USD 用 `amount`，非 USD 用 `revneue+fee`。不要再 `/rate/100`。
- 按 `transaction_id` 去重。PayInsider 与 HI 对齐：`gateway_transaction_id=transaction_id` **或** `user_id + |event_timestamp|≤10`。
- 俄罗斯移动支付：`UPPER(currency)='RUB'`，且 app 映射为 `collart-android` / `vidart-ios`。

## 6. 数据质量与风险提示
-此表有重复数据，因此在分析计算前以transaction_Id为基础，进行去重处理
- 每日约北京 8 点刷新到昨天；查「今天」本表会空。不要用 `dwd_cdct_orders_revenue_hi` 补（0 行）。当天未进 T+1 就等次日，或说明是 T+1 口径。

## 7. 典型使用场景与示例 SQL
###1 计算不同国家每天的首次订阅收入、续订收入和点数包收入  
``` 
 select event_date
,c.country_name country
,sum(case when revneue>0 then revneue end) revenue
,sum(case when description_type ='Subscription creation' then revneue end)  new_revenue
,sum(case when description_type = 'Subscription update' then revneue end) renew_revenue
,sum(case when  revneue>0 and description_type='credit'  then revneue end) pack_revenue
from (select distinct event_date
,event_timestamp
,transaction_Id
,app_name
,charge_type
,country
,stripe_customer_id
,amount
,fee
,revneue
,description_type
,product_name
from pubdata2025.dwd.dwd_cdct_revenue_stripe_di) a
left join hzdw2024.hz_dim.dim_country c on lower(if(a.country='Russia','ru',a.country))=lower(country_name_3)
where a.country is not null 
and revneue>0
group by all
```
