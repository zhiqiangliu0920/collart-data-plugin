# `aidata2025.ads_collart.ads_oper_user_revenue_collart_fashion_di`

> **2026-09-09 停写**。改读 `ads_collartfashion.ads_oper_user_revenue_di`（订单）和 `ads_oper_user_active_di`（用户日）。

## 1. 基础信息

- 中文名：【停更】Collart Fashion 用户日 Stripe 收入表
- 表类型：ADS 用户日事实表
- 行粒度：`event_date × user_id`
- 分区字段：`event_date`
- 聚簇字段：`user_id`
- 更新频率：T+1，默认回刷 7 天
- 生效日期：2026-08-27；支付事件直连归因自 2026-08-28 生效
- 历史回填：2026-06-01 起
- 上游：
  - `pubdata2025.dwd.dwd_cdct_revenue_stripe_di`
  - `aidata2025.dm.dm_collart_web_user_event_di`

## 2. 核心作用

- 提供用户粒度的 Fashion 实际收入、付费人数和交易笔数。
- 作为 `ads_oper_revenue_collart_fashion_di` 日汇总的唯一收入明细来源。
- 支持按 `user_id` 复核 Fashion 付费用户和后续 LTV。

## 3. 核心字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `event_date` | DATE | Stripe 收入日期 |
| `package_name` | STRING | 固定 `collart_fashion` |
| `user_id` | STRING | Collart 登录用户 ID |
| `user_pseudo_id` | STRING | 与该交易最近的支付成功事件对应 GA4 用户 ID；供 active 收入行映射 |
| `first_fashion_succeed_date` | DATE | 该登录用户首次 Fashion `vip_subscribe_succeed` 日期 |
| `revenue_usd` | FLOAT64 | Stripe 用户当日收入 USD |
| `pay_cnt` | INT64 | 按 `transaction_id` 去重后的交易笔数 |
| `etl_time` | TIMESTAMP | 入库时间 |

## 4. 口径与红线

1. Stripe 限定 `app_name = 'collart_web'`、`revneue > 0`、`user_id` 非空，并按 `transaction_id` 去重。
2. 每笔 Stripe 交易按 `user_id` 匹配交易时间前后 10 分钟内最近的 `vip_subscribe_succeed`；时间比较使用 `event_timestamp` 与 `TIMESTAMP(event_time)`，不比较两表的 `event_date`。
3. 最近支付成功事件的 `package_name` 必须为 `collart_fashion`；若最近事件在 `collart_web`，不得归给 Fashion。无 10 分钟内事件的交易也不归因。
4. `event_date` 仍取 Stripe 收入日期；支付成功事件的 `user_pseudo_id` 随行保存，解决 GA4 日期跨日时 active 无法映射的问题。
5. 排除 Collart Web / Fashion 内部用户。
6. 金额和交易笔数以 Stripe 为真值；`vip_subscribe_succeed` 只用于交易场景归属。

## 5. 血缘

`dm_collart_web_user_event_di.vip_subscribe_succeed + Stripe（user_id + 时间近邻）` → `ads_oper_user_revenue_collart_fashion_di`  
`ads_oper_user_revenue_collart_fashion_di` → `ads_oper_revenue_collart_fashion_di` → Fashion 核心指标/日报

## 6. 数据质量

- 历史的“首次 Fashion succeed 后全部 Stripe 收入归 Fashion”口径会把后续主站购买误归 Fashion；已废弃。
- 历史以 `event_date` 比较 Stripe 与 GA4 的口径会因时区跨日漏掉真实 Fashion 交易；已废弃。
- 2026-08-14～2026-08-27 按新口径回填后：10 个付费用户、16 个用户日、17 笔交易、收入 392.44 USD。
- 表要求分区过滤；查询必须限制 `event_date`。

## 7. 示例 SQL

```sql
SELECT
  event_date,
  user_id,
  first_fashion_succeed_date,
  revenue_usd,
  pay_cnt
FROM `aidata2025.ads_collart.ads_oper_user_revenue_collart_fashion_di`
WHERE event_date BETWEEN DATE_SUB(CURRENT_DATE('Asia/Shanghai'), INTERVAL 7 DAY) AND CURRENT_DATE('Asia/Shanghai') - 1
ORDER BY event_date, revenue_usd DESC;
```
