## 明确修正

1. country_metrics 不再将 retain2_free 冒充全部新增次留；改读 retain.d2，率的分母只取同样成熟的 DNU。
2. 删除 new_subscribe_uv/dnu 被命名为新增付费率的写法；首购订阅用户可能是历史访客，模板只输出分类人数。
3. 四端模板移除不保证同构的分类 UV，按端输出，不把 Web 与 Fashion 重叠收入求总和。
4. profile cohort 明确不是完整历史新增人群，排除内部账号，未成熟留存保持 NULL。
5. 区分订阅点击、埋点成功、实际成功支付和历史 VIP；分类付费 UV 不直接相加。
6. RUB 过滤仅作用于移动端俄罗斯 Stripe 补充支付，不限制整个 Web 支付。
7. 不再隐瞒查询失败、不强制切换凭证、不因缺列自动部署、不把历史事故和经营目标视为永久现状。
8. 将 18 个内部测试账号集中为唯一配置，来源快照隐藏重复 ID 和个人安装路径；没有复制密钥或普通用户行为记录。
